# Tiều phu và những viên đá màu (tên tạm)

Game 2D Metroidvania ngắn (30–40 phút), side-scroll, cận chiến bằng rìu. Đồ án môn SE220.

Thế giới chỉ còn trắng, đen và xanh băng nhạt. Một ông tiều phu lần theo dấu những người phiêu lưu đã chết để thu 3 viên đá màu và trả màu cho thế giới.

## Yêu cầu

- **Unity 6.6 (6000.6.7f1)** (URP 2D)
- Git + Git LFS
- PC Windows 10/11, bàn phím hoặc tay cầm XInput

## Bắt đầu

```bash
git clone https://github.com/Ender-Via/SE220.git
cd SE220
git lfs install
git lfs pull
```

Mở bằng Unity Hub → **Add → Add project from disk**.
